# semantic-data-type

A LinkML schema defining Semantic Data Types (SDTs). An SDT serves as an intelligent bridge between high-level data type concepts and the ways they are commonly represented in files, databases, and programming environments. By formalizing metadata, mappings, validation, generation, and agentic instructions, this model enables both humans and AI agents to develop a deep, actionable understanding of the underlying data.

URI: https://w3id.org/dartfx/semanticdt
